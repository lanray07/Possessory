# Typography proofs only

These images test shaping of Arabic and Indic text and Japanese font fallback using tools/render_marketing.cjs. They are not final marketing assets or current-version screenshots. The application pixels retain their original capture provenance.

Use POSSESSORY_NODE_MODULES to locate a local Playwright installation and POSSESSORY_CHROMIUM for an installed Chromium executable. The renderer blocks external requests and reads only the supplied local capture files. No browser-console access is provided by this renderer.
