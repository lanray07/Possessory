# Possessory 0.3.0 candidate verification

This is an engineering verification record, not Amazon submission approval. It supersedes the older 0.1.0 preview notes. Final results and artifact hashes are recorded in release-verification.json after the checks finish.

Completed before the final candidate rebuild: 30 Android JVM/rendered UI tests; eight receipt-verifier tests; five translation-pipeline tests; server dependency audit with no known vulnerabilities; 19 draft locale catalogues with 335 messages each and no missing keys or placeholder mismatches. All fourteen OCR models initialized and returned text in a synthetic receipt smoke test on a real KFTRWI Fire tablet. Native PDF pagination/rendering and a small encrypted-backup round trip passed. This synthetic test is not an OCR accuracy evaluation in fourteen languages.

The first 99 MiB native backup test failed with Fire Conscrypt buffering and an OutOfMemoryError. The candidate now uses explicit Bouncy Castle streaming AES-GCM and private disk staging for restore attachments. The rerun passed on the physical Fire tablet: 99 MiB of attachments encrypted, decrypted, authenticated, checksummed and staged for preview in 35.374 seconds. The backup file format remains compatible with earlier encrypted backups; JVM tests cover cross-provider compatibility, wrong-password and tamper rejection. Metadata is capped at 8 MiB and total decompressed archives at 100 MiB.

An initial seven-screen navigation pass completed for all nineteen draft locales. Some captures preceded the final display frame; those files are not handoff evidence. Final captures require expected-screen assertions, display synchronization, the final review APK hash and provenance. A scrollable sidebar addresses text-expansion/navigation overflow. The final synchronized capture pass passed all nineteen locales (133 images). English/German/Arabic navigation passed at 200% text size and in portrait (42 further images). The final handoff contains 175 raw captures with APK/source/per-image hashes. The signed production update also retained the pre-existing demo household, three rooms, six items and maintenance record.

Independent human language/region/plural review, accessibility and external camera/speech/notification checks, production receipt-verifier hosting/secrets, and real Amazon purchase/restore/cancellation testing remain required. No machine draft is marked human-reviewed or release-approved. The separate .review APK provides evaluation tools without granting an Amazon entitlement and must never be submitted. The Amazon draft still contains the older 0.2.0 binary until a candidate is approved.

Owner: O. Bankole; support: banksmi@mail.com. Premium base price approved at GBP 4.99 once, no subscription. Amazon entitlement SKU possessory.premium.lifetime remains an unsubmitted draft. No export declaration or store submission has been made.

Final Amazon and standalone release builds passed. Lint reports contain zero errors, respectively 40 and 41 warnings. Warnings are classified in release-verification.json; they include dependency-version suggestions, style/API cleanup, unused resources and backup/locale configuration review. They are not represented as zero-warning results or as completed manual approval.
